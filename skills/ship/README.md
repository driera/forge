# ship

Closes the issue lifecycle after a clean review.

## When to use

Say "ship", "close the issue", or "we're done" — or run it when `review` gives you the no-blockers handoff.

## What it does

- Closes the GitHub issue
- Checks the milestone — if all issues are done, closes it too
- Checks `GOALS.md` — if a goal is now achieved, marks it done (with your confirmation)
- Commits any artifact updates
